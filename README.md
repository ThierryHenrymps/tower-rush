# Tower Rush

**Um jogo arcade de empilhamento de blocos, desenvolvido como projeto do Bootcamp Itaú, com auxílio de ferramentas de Inteligência Artificial.**

---

## Sobre o projeto

Tower Rush é um projeto desenvolvido durante o Bootcamp Itaú, com o objetivo de colocar em prática conhecimentos de programação, desenvolvimento de software e utilização de ferramentas de Inteligência Artificial.

O jogo consiste em posicionar blocos com precisão para construir a torre mais alta possível.

O projeto busca proporcionar uma experiência envolvente, combinando elementos visuais tridimensionais, animações, cores personalizáveis e uma estética inspirada em ilhas flutuantes.

## Funcionalidades

- Sistema de empilhamento de blocos.
- Elementos visuais com aparência tridimensional.
- Cenário com estética de ilhas flutuantes.
- Animações na tela inicial.
- Sistema de recorde e pontuação máxima.
- Personalização das cores dos blocos.
- Interface de loja para personalização.
- Dificuldade progressiva durante a partida.

## Desenvolvimento com Inteligência Artificial

Durante o desenvolvimento, foram utilizadas ferramentas de Inteligência Artificial como apoio em diferentes etapas do projeto, incluindo:

- Auxílio na implementação de funcionalidades.
- Identificação e resolução de erros.
- Experimentação de interfaces e experiências visuais.
- Engenharia de prompts.
- Refatoração e melhorias no código.

As implementações foram analisadas, revisadas e testadas durante o processo de desenvolvimento.

## Tecnologias utilizadas

- Android Studio
- Kotlin e Jetpack Compose
- Gradle
- Hermes agent 
- API Gemini
- Chat GPT assisted development

## Como executar o projeto

### Clonar o repositório

```bash
git clone https://github.com/ThierryHenrymps/tower-rush.git
```

### Acessar a pasta

```bash
cd tower-rush
```

### Instalar dependências

```bash
Minimum SDK: 24 (Android 7.0).

Compile SDK: 37.

Target SDK: 37.

Java Compatibility: 11.
```

### Executar o projeto

```bash
# Rode pelo emulador, ou inicie o app pelo celular 
```
